# HLL Default Garrisons

A lightweight intel tool for **Hell Let Loose** offensive matches. It highlights the default defender garrison locations across every offensive map so squad leads, armor crews, and artillery teams can plan their opening moves without guesswork.

## Features

- Interactive map viewer with zoom + scale readouts.

## Development Notes

- Source styles live in `css/style.css`; client logic is in `js/script.js`.
- Map imagery is in `images/maps`, while UI assets live under `images/ui`.
